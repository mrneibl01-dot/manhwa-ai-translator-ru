# Manhwa AI Translator RU (v5.2)

Бесплатное расширение с открытым исходным кодом для **Chrome, Brave, Edge, Opera и Яндекс Браузера**, которое автоматически переводит манхву, мангу и вебтуны с английского на живой литературный русский язык прямо поверх картинок с помощью нейросети **Google Gemini**.

---

## ✨ Возможности

- **🚀 Фоновая предзагрузка всей главы:** пока вы читаете первую страницу, расширение в фоне переводит всю главу до конца.
- **⚡ Пакетный режим (3–4 страницы за 1 запрос):** экономит бесплатный лимит API в 4 раза — одного бесплатного ключа Google (500 запросов/сутки) хватает на **65–80 полных глав в день**.
- **✂ Мгновенный перевод выделенной области (`Alt + S`):** нажмите боковую кнопку `✂` справа на экране, выделите мышкой любой бабл или кусок картинки — перевод появится поверх него за 1–2 секунды.
- **🎨 Аккуратные плашки без торчащего английского:** автоматический подбор цвета фона облачка/системного окна, плотная заливка, мягкие края, сохранение целых русских слов и пропуск рисованных звуков (SFX).
- **📚 Встроенный словарь манхвы:** правильный литературный перевод терминов (Созвездия, Сценарии, Воплощения, Токкэби, Подземелья, Мурим и т.д.).
- **🔑 Поддержка нескольких ключей + кэш на диске:** можно вставить 2–5 бесплатных ключей с новой строки для автопереключения, а уже переведённые главы сохраняются на диске (после `F5` тратится 0 запросов).
- **📖 Встроенный гайд внутри расширения:** нажмите **`? Гайд`** в правом верхнем углу окна расширения, чтобы в любой момент посмотреть описание всех кнопок и настроек.

## 🛡 Безопасность и отсутствие вирусов

Весь код расширения полностью открыт и читаем прямо в этом репозитории — здесь нет скомпилированных `.exe`-файлов, скрытых скриптов или обфускации. Любой желающий может открыть каждый файл и убедиться:

| Файл | За что отвечает |
| :--- | :--- |
| `manifest.json` | Паспорт расширения и список прав браузера (Manifest V3) |
| `background.js` | Нарезка картинок, пакетная отправка в официальный API Google и кэш |
| `content.js` / `content.css` | Отрисовка русских баблов, кнопка `✂` и мини-панель прогресса |
| `popup.html` / `popup.js` | Окно настроек расширения и встроенный `? Гайд` |

- **Никаких сторонних серверов и телеметрии:** картинки и запросы уходят напрямую из вашего браузера на официальный сервер Google (`https://generativelanguage.googleapis.com`).
- **Локальное хранение ключей:** ваш API-ключ сохраняется только в локальном хранилище вашего браузера (`chrome.storage.local`).
- **Не мешает другим сайтам:** по умолчанию расширение выключено везде и запускается только на тех сайтах, где вы сами включили тумблер.

## 📥 Установка (2 минуты)

1. Скачайте последний архив **`ManhwaAutoTranslate-RU-v5.2-GitHub.zip`** из раздела **[Releases](../../releases)** справа на странице (либо нажмите зелёную кнопку **`<> Code` → `Download ZIP`**).
2. **Распакуйте архив** в любую постоянную папку (например, `C:\ManhwaTranslator`) и не удаляйте её потом.
3. Откройте в браузере страницу расширений:
   - Для **Chrome / Яндекс / Opera**: введите в адресной строке `chrome://extensions`
   - Для **Brave**: `brave://extensions`
   - Для **Edge**: `edge://extensions`
4. В правом верхнем углу включите **«Режим разработчика»** (*Developer mode*).
5. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку, куда вы распаковали архив.
6. Нажмите на значок пазла рядом с адресной строкой и закрепите иконку **Manhwa AI → RU**.

## 🔑 Как получить бесплатный ключ Gemini (карта не нужна)

1. Нажмите на иконку **Manhwa AI → RU** в браузере и кликните по ссылке **«Получить бесплатный ключ (Google AI Studio)»** (или перейдите на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)).
2. Войдите в свой Google-аккаунт и нажмите **Create API key**.
3. Скопируйте полученный ключ, вставьте его в поле внутри расширения и нажмите **«Сохранить и проверить»** — появится зелёная надпись **`Работает!`**.
4. Откройте любой сайт с манхвой на английском, нажмите на иконку расширения и включите тумблер **«Автоперевод этого сайта»**.

> **Совет:** если вы читаете больше 70 глав в день, можно создать бесплатные ключи на 2–3 Google-аккаунтах и вставить их в поле **каждый с новой строки** — расширение будет автоматически переключаться между ними.

## ⌨️ Горячие клавиши и управление

| Действие | Управление |
| :--- | :--- |
| Вырезать и мгновенно перевести область (1–2 сек) | `Alt + S` или кнопка `✂` справа |
| Скрыть / вернуть весь перевод на странице | `Alt + H` |
| Включить / выключить автоперевод для текущего сайта | `Alt + T` |
| Посмотреть английский оригинал одного бабла | Клик мышкой по этому баблу |
| Удалить вырезанную область `✂` | Навести курсор и нажать `×` |
