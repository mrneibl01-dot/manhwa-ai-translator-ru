====================================================
  Manhwa AI Translator RU (v5.2) — Инструкция
====================================================

1. УСТАНОВКА В БРАУЗЕР (Chrome / Brave / Edge / Opera)
----------------------------------------------------
Шаг 1. Распакуйте этот архив в любую удобную папку
       (например, C:\ManhwaTranslator) и НЕ удаляйте её потом.
Шаг 2. Откройте в браузере страницу расширений:
       - Brave:  brave://extensions
       - Chrome: chrome://extensions
       - Edge:   edge://extensions
Шаг 3. В правом верхнем углу включите «Режим разработчика»
       (Developer mode).
Шаг 4. Нажмите «Загрузить распакованное расширение» (Load unpacked)
       и выберите папку с распакованными файлами.
Шаг 5. Нажмите на значок пазла в правом верхнем углу браузера
       и закрепите иконку «Manhwa AI → RU».


2. БЕСПЛАТНЫЙ КЛЮЧ НЕЙРОСЕТИ (1 минута, карта не нужна)
----------------------------------------------------
Шаг 1. Нажмите на иконку «Manhwa AI → RU».
Шаг 2. Нажмите внутри ссылку «Получить бесплатный ключ (Google AI Studio)»
       или откройте https://aistudio.google.com/apikey
Шаг 3. Войдите в Google-аккаунт → нажмите Create API key → скопируйте ключ.
Шаг 4. Вставьте ключ в поле внутри расширения и нажмите
       «Сохранить и проверить» (появится зелёная надпись «Работает!»).
Шаг 5. Откройте любой сайт с мангой/манхвой на английском,
       нажмите на иконку расширения и включите «Автоперевод этого сайта».


3. ВСТРОЕННЫЙ ГАЙД И ГОРЯЧИЕ КЛАВИШИ
----------------------------------------------------
В правом верхнем углу окна расширения есть кнопка «? Гайд» —
там подробно описана каждая кнопка, галочка и настройка.

Горячие клавиши:
  Alt + S  — выделить мышкой область и перевести её за 1–2 сек
  Alt + H  — быстро скрыть / показать весь перевод
  Alt + T  — включить / выключить перевод для текущего сайта
  Клик по переведённому баблу — подсмотреть английский оригинал


4. БЕЗОПАСНОСТЬ
----------------------------------------------------
Код полностью открыт и состоит из обычных текстовых файлов (.js/.html/.css).
Ключи хранятся только локально в вашем браузере; картинки отправляются
напрямую в официальный API Google (generativelanguage.googleapis.com).
